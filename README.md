# 🐍 Snake Game in C

A classic Snake Game built using C, featuring a colorful terminal interface, increasing difficulty, bonus rewards, and a scoring system.

## ✨ Features

* Classic Snake gameplay.
* WASD and arrow key controls.
* Increasing speed as you level up.
* Score and high-score tracking.
* Golden bonus food (+50 points).
* Pause and resume functionality.
* Restart after Game Over.
* Windows and Linux support.

## 🎮 Controls

| Key   | Action         |
| ----- | -------------- |
| W / ↑ | Move up        |
| S / ↓ | Move down      |
| A / ← | Move left      |
| D / → | Move right     |
| P     | Pause / Resume |
| Q     | Quit           |
| R     | Restart        |

## 💻 Download and Play

Choose the executable for your operating system from this repository.

**Windows**

Download `snake.exe` and run it in your terminal or by double-clicking it.

**Linux**

Download `snake` and run:

```bash
chmod +x snake
./snake
```
